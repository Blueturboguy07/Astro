Astro 0.2.5 fixes the defects that a full test of 0.2.4 on macOS and Windows found.

- Agent extension 0.0.115. The local server is built from this release.
- The browser is the same as 0.2.4: Chromium 148 on macOS, Chromium 151 on Windows.
- Finder shows the version 0.2.5.

## Fixed

### Answers and web search

- Web search works on the first question. The search setup no longer stops the local server, and opening a new tab no longer kills a running task.
- With publik only, web results are no longer dropped. Pages that share only a number or a common word with the question are no longer cited.
- When web search fails, Astro says which engines failed and writes no answer without sources.
- After **Connect your plan**, the default model is publik Balanced.
- Academic searches use OpenAlex, Semantic Scholar, Crossref, PubMed, Google Scholar and arXiv. Social searches use Reddit, Hacker News and Lemmy.
- **Stop** and a reload in the middle of an answer no longer stop the local server.
- **Stop** no longer sends a question that waits in the input box.
- **Delete chat** goes back to the home page.
- **Export chat → PDF** prints formatted text and the export time.
- Code blocks in answers show their text.
- A provider that refuses a question shows a failed answer with the provider's message and **Retry**.
- The usage line of a publik answer says "billed by publik" and shows no invented total.

### Side panel and agent tasks

- The side panel lists publik Balanced, Fast and Smart. After **Use my own key** it lists only your own connections.
- An answer stream that stops sending data now ends with an error instead of a Stop button that stays.
- A task stops when the page stays on a loading screen or when it reaches its action limit, and the report says how to continue. Chat Mode stops after 8 actions.
- Page dialogs, file uploads and Ollama tool calls work in agent tasks.
- Tool rows open and show their input and output.
- On macOS a sandbox keeps the agent's shell commands inside the workspace folder. On Windows a path check refuses paths outside it.
- Scheduled tasks run in a hidden window. A run that stopped is marked as stopped.

### Account, money and limits

- A daily limit or an empty balance shows a clear message with a top-up link.
- When publik does not answer, Astro keeps your last choice and shows "publik is not answering." with **Retry**.
- Settings shows your publik account with **Switch publik account** and **Sign out of publik**. The old account sign-in page is gone.
- The extension no longer asks an upstream account service for a session on every page.

### Settings and privacy

- `chrome://settings` opens on macOS. The paks are rebuilt from the original files.
- The key dialog says the truth: keys are stored on this computer, not encrypted. The settings file is readable by your user only (mode 0600).
- The MCP setup snippets use the name `astro`. Claude Desktop has a manual setup row.
- The local server listens on 127.0.0.1 only.

### Windows

- The installer carries Astro's own local server. The answer engine works on Windows.

### macOS

- The crash bubble says "Astro didn't shut down correctly" (English only).

## Known limits

- The browser's MCP proxy listens on all network interfaces. Other computers get no answer, but a port scan sees the ports. The fix needs a new browser build.
- At the first start the browser tries to install the agent extension once. On a slow start the agent can be missing until the next start.
- `chrome://flags`, the bookmarks and history pages and the onboarding page still show upstream names and the upstream logo. Activity Monitor and Task Manager show the helper processes with upstream names.
- Provider keys are stored in plain text in a file that only your user can read.
- The agent's shell commands can still use the network.
- Connectors (**Connect apps**) still use the upstream project's proxy.
- Voice input goes to publik transcription and is billed to your publik account. With your own keys only, there is no voice input.
- A reload in the middle of an answer stops that answer. Astro shows a note and **Retry**; it cannot continue the answer.
- There are no automatic updates. To update, download the new version.
- `Astro-Setup.exe` is unsigned. In SmartScreen click **More info**, then **Run anyway**.

## Files

- `Astro.dmg`: macOS, Apple silicon. Signed with a Developer ID, notarized by Apple, stapled.
- `Astro-Setup.exe`: Windows x64 installer, unsigned.
- `astro-agent.crx`: the agent extension 0.0.115 that both builds carry.
- `SHA256SUMS.txt`: the SHA-256 of each file.

## Windows and Linux

`Astro.dmg` is macOS (Apple silicon) only. Windows: download `Astro-Setup.exe` above, or follow https://publikhq.com/astro/install/windows. Linux: there is no Linux build; run Astro on top of BrowserOS as described in https://github.com/Blueturboguy07/Astro/blob/main/SETUP.md
