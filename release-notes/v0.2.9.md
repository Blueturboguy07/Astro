# Astro 0.2.9

No change in what Astro does. This release proves the one-command release script.

- **From 0.2.7 or 0.2.8:** Astro finds 0.2.9 by itself. Select **Install Update** in the update window.
- **From 0.2.6 or older:** download Astro one more time. Those versions do not find new versions.

## Windows and Linux

`Astro.dmg` is macOS (Apple silicon) only. Windows: download `Astro-Setup.exe`
above, or follow https://publikhq.com/astro/install/windows. Linux: there is no
Linux build; run Astro on top of BrowserOS as described in
https://github.com/Blueturboguy07/Astro/blob/main/SETUP.md
