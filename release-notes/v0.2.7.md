Astro 0.2.7 updates itself. This is the last version that you download by hand.

- Agent extension 0.0.116. Local server 0.0.128. Both are the same as in 0.2.6.
- The browser is the same as 0.2.6.
- Finder shows the version 0.2.7.

## New

- **Updates:** Astro checks for a new version at start and one time each hour. It installs a new version only when the package carries Astro's signature. The menu item **Check for Updates…** starts a check at once.
- **macOS:** Astro shows the new version. Select **Install Update**: Astro downloads it, installs it and starts again.
- **Windows:** Astro shows the new version and installs it when you select **Install update**. Windows asks for administrator rights, because Astro is in Program Files. A failed update writes the reason to `%TEMP%\astro-update.log` and changes nothing.

Astro 0.2.6 and older do not find this version by themselves. Download 0.2.7 one time.

## Known limits

- On Windows, the update window says "BrowserOS" in two lines of text. The update that it installs is Astro.
- The known limits of 0.2.5 still apply: https://github.com/Blueturboguy07/Astro/releases/tag/v0.2.5

## Files

- `Astro.dmg`: macOS, Apple silicon. Signed with a Developer ID, notarized by Apple, stapled.
- `Astro-Setup.exe`: Windows x64 installer, unsigned.
- `Astro-Update.exe`: the Windows update package that Astro downloads by itself. Do not download it by hand.
- `astro-update.json`: the signatures of the update packages.
- `astro-agent.crx`: the agent extension 0.0.116 that both builds carry.
- `SHA256SUMS.txt`: the SHA-256 of each file.

## Windows and Linux

`Astro.dmg` is macOS (Apple silicon) only. Windows: download `Astro-Setup.exe` above, or follow https://publikhq.com/astro/install/windows. Linux: there is no Linux build; run Astro on top of BrowserOS as described in https://github.com/Blueturboguy07/Astro/blob/main/SETUP.md
