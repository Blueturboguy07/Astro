Astro 0.2.6 fixes the side panel input box that cleared while you typed.

- Agent extension 0.0.116. Local server 0.0.128.
- The browser is the same as 0.2.5.
- Finder shows the version 0.2.6.

## Fixed

- **Side panel:** the text you type no longer disappears. Before, when the local server could not list your agents, the side panel showed a spinner about every 12 seconds and came back with an empty input box. A background refresh now never removes the input box. If the input box is drawn again, your unsent text comes back.
- **Local server:** Astro and upstream BrowserOS share one database in `~/.browseros`. A newer BrowserOS removes a table that Astro needs, so the agents list failed with "no such table: agent_definitions". At start, Astro's server now creates the missing tables again. It changes nothing else in the database. Agents that the newer BrowserOS removed do not come back.

## Known limits

The known limits of 0.2.5 still apply: https://github.com/Blueturboguy07/Astro/releases/tag/v0.2.5

## Files

- `Astro.dmg`: macOS, Apple silicon. Signed with a Developer ID, notarized by Apple, stapled.
- `Astro-Setup.exe`: Windows x64 installer, unsigned.
- `astro-agent.crx`: the agent extension 0.0.116 that both builds carry.
- `SHA256SUMS.txt`: the SHA-256 of each file.

## Windows and Linux

`Astro.dmg` is macOS (Apple silicon) only. Windows: download `Astro-Setup.exe` above, or follow https://publikhq.com/astro/install/windows. Linux: there is no Linux build; run Astro on top of BrowserOS as described in https://github.com/Blueturboguy07/Astro/blob/main/SETUP.md
