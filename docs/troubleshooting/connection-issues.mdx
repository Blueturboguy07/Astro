title: "Has Agent Crashed?"
description: "How to fix connection issues when Astro's local server is not responding"
---

If the side panel says **"Connection failed. Astro could not reach its local server"** (or **"Astro lost the connection to its local server during the answer"**), or the new tab says **"Can't reach the local Astro server"**, Astro's local server has stopped. It restarts by itself: try again after a few seconds. If that does not help, use the steps below.

<Note>Astro's local server is a separate program next to the browser. Its file keeps its upstream BrowserOS name: `browseros_server` on macOS and Linux, `browseros_server.exe` on Windows. On Windows, the **Processes** tab of Task Manager shows it as **Bun**, and the **Details** tab shows it as `browseros_server.exe`.</Note>

## Windows: did you allow Astro's local server through the firewall?

When Astro starts for the first time on Windows, Windows Security may ask if you want to allow an app to access public and private networks. That app is Astro's local server. Windows shows it with the name **Bun**; click **Show more** to see its path, which ends in `browseros_server.exe`. Click **Allow**. The local server needs this permission. If you clicked **Cancel** or missed this prompt, Astro cannot reach its local server.

To fix this, go to **Windows Security → Firewall & network protection → Allow an app through firewall**. Find the entry for `browseros_server.exe` (shown as **Bun**) and allow it.

## Fix It

<Steps>
  <Step title="Go to Settings → Astro as MCP and restart the server">
    Open **Settings** from the sidebar and open **Astro as MCP**. Next to the **Server URL**, click the **Restart server** button (the circular arrows). Wait a couple of minutes.
  </Step>

  <Step title="If that does not work, stop the local server and restart Astro">
    <Tabs>
      <Tab title="Windows">
        1. Open **Task Manager**: press `Ctrl + Shift + Esc`, or right-click the taskbar and select **Task Manager**.
        2. Open the **Details** tab and find `browseros_server.exe`. (On the **Processes** tab, the same program shows as **Bun**.)
        3. Right-click `browseros_server.exe` and select **End task**.
        4. Quit Astro and open it again. Astro starts its local server when it starts.

        <Note>If Astro still cannot reach its local server, end both **Astro** and `browseros_server.exe` in Task Manager, then open Astro again.</Note>
      </Tab>
      <Tab title="macOS">
        Right-click Astro in the Dock → **Quit**, then open Astro again.
      </Tab>
    </Tabs>
  </Step>
</Steps>

## Still Not Working?

<AccordionGroup>
  <Accordion title="Check the ports Astro uses">
    Astro has no fixed ports. Each time it starts, the browser picks free ports for its local server, the MCP proxy and the browser's debugging (CDP) connection. The numbers can be different on your computer and can change from one start to the next.

    To read the port that MCP clients use, open **Settings → Astro as MCP**. The **Server URL** has the form `http://127.0.0.1:<port>/mcp`. To use a different port, click the pencil button (**Edit server port**) next to the URL.

    To see which program listens on a port, replace `<port>` with the number:

    <Tabs>
      <Tab title="macOS/Linux">
        ```bash
        lsof -nP -iTCP:<port> -sTCP:LISTEN
        ```
      </Tab>
      <Tab title="Windows">
        ```powershell
        netstat -ano | findstr :<port>
        ```

        The last column is the process ID (PID). Find that PID in the **PID** column of the **Details** tab of Task Manager.
      </Tab>
    </Tabs>

    If another program holds the port that you set, choose a different port with **Edit server port**, or close that program. Then restart Astro.
  </Accordion>

  <Accordion title="Check your firewall or antivirus settings">
    Some firewalls block local connections. Make sure that your firewall lets Astro and its local server (`browseros_server`, on Windows `browseros_server.exe`) connect to `127.0.0.1`.

    **Windows users:** Antivirus software sometimes triggers a false positive. Try temporarily disabling your antivirus and restarting Astro.
  </Accordion>
</AccordionGroup>
