---
title: "Has Agent Crashed?"
description: "How to fix connection issues when Astro's local server is not responding"
---

If the side panel says **"Connection failed. Astro could not reach its local server"** (or **"Astro lost the connection to its local server during the answer"**), or the new tab says **"Can't reach the local Astro server"**, Astro's local server has stopped. It restarts by itself: try again after a few seconds. If that does not help, use the steps below.

<Note>On Windows, Task Manager and the firewall show Astro's local server as **BrowserOS Agent** (`browseros_server.exe`), its upstream name.</Note>

<Frame>
  <img src="/troubleshooting/failed-to-fetch-error.png" alt="Failed to fetch error" />
</Frame>

## Windows: Did you allow the BrowserOS Agent (Astro's local server)?

When Astro starts for the first time on Windows, a popup may ask if you want to allow **BrowserOS Agent** (Astro's local server) to access the network. Click **Allow** — the agent runs as a separate process alongside the browser and needs this permission to work. If you clicked **Cancel** or missed this prompt, the agent won't be able to connect.

<Frame>
  <img src="/troubleshooting/windows-installation-allow-browseros-agent.png" alt="Allow BrowserOS Agent network access prompt" />
</Frame>

To fix this, go to **Windows Security → Allow an app through your network settings**, and make sure **BrowserOS Agent** is enabled.

## Fix It

<Steps>
  <Step title="Go to Settings → Astro as MCP and click Restart server">
    Open **Settings** from the sidebar, open **Astro as MCP**, and click **Restart server**. Wait a couple of minutes.

    <Frame>
      <img src="/troubleshooting/mcp-server-restart.png" alt="Click Restart in MCP Server Settings" />
    </Frame>
  </Step>

  <Step title="If restart doesn't work, restart the BrowserOS Agent manually">
    <Tabs>
      <Tab title="Windows">
        1. Open **Task Manager** — press `Ctrl + Shift + Esc` or right-click the taskbar and select **Task Manager**.
        2. In the search bar at the top, type **browseros agent**.
        3. Right-click **BrowserOS Agent** and select **End task**.
        4. Reopen **Astro** — the agent will restart automatically.

        <Frame>
          <img src="/troubleshooting/troubleshoot-search-restart-agent-task-manager.png" alt="Search for BrowserOS Agent in Task Manager and restart it" />
        </Frame>

        <Note>If the agent still doesn't reconnect, end both **Astro** and **BrowserOS Agent** in Task Manager, then reopen the app.</Note>
      </Tab>
      <Tab title="macOS">
        Right-click Astro in the Dock → **Quit**, then reopen the app.
      </Tab>
    </Tabs>
  </Step>
</Steps>

## Still Not Working?

<AccordionGroup>
  <Accordion title="Check if another application is using the port">
    The agent runs on port `9100` by default. If another application is using this port, Astro cannot start the agent.

    <Tabs>
      <Tab title="macOS/Linux">
        Find the process:
        ```bash
        lsof -i :9100
        ```

        Kill it (replace `PID` with the process ID from above):
        ```bash
        kill -9 PID
        ```
      </Tab>
      <Tab title="Windows">
        Find the process:
        ```powershell
        netstat -ano | findstr :9100
        ```

        Kill it (replace `PID` with the process ID from above):
        ```powershell
        taskkill /PID PID /F
        ```
      </Tab>
    </Tabs>

    Then restart Astro.
  </Accordion>

  <Accordion title="Check your firewall or antivirus settings">
    Some firewalls may block local connections. Make sure your firewall allows connections to `127.0.0.1:9100`.

    **Windows users:** Antivirus software sometimes triggers a false positive. Try temporarily disabling your antivirus and restarting Astro.
  </Accordion>
</AccordionGroup>
