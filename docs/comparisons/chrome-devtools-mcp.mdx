Both Astro MCP and [Chrome DevTools MCP](https://github.com/ChromeDevTools/chrome-devtools-mcp) give AI agents control over a browser via the Model Context Protocol. But they're built for different scopes. Chrome DevTools MCP focuses on debugging and inspection, while Astro MCP focuses on browser automation and app integrations.

This page breaks down the differences for developers evaluating which to use with Claude Code, Gemini CLI, Cursor, or any MCP client.

---

## At a Glance

| | **Astro MCP** | **Chrome DevTools MCP** |
|---|---|---|
| **Total MCP tools** | 23 (16 browser tools, 7 connected-app tools) | 29 |
| **External app integrations** | 45 (Gmail, Slack, GitHub, etc.) | None |
| **Setup** | Copy URL from settings, works instantly | Requires `--remote-debugging-port` flag and separate server process |
| **Browser session** | Your real browser with cookies, logins, extensions | Attached debug session (some sites block WebDriver-controlled browsers) |
| **Architecture** | Built into the browser | External Node.js process connecting via CDP |

## Feature Comparison

Astro MCP has fewer tools, and each tool has several actions (for example, `act` clicks, types, fills, scrolls and drags).

### Navigation & Tab Management

| Feature | Astro MCP | Chrome DevTools MCP |
|---------|:---:|:---:|
| Navigate to URL / back / forward / reload | `navigate` | `navigate_page` |
| Open, close, list tabs; get the active tab | `tabs` | `new_page`, `close_page`, `list_pages` |
| Switch to tab | - | `select_page` |
| Wait for a time, text, or selector | `wait` | `wait_for` |

### Content & Observation

| Feature | Astro MCP | Chrome DevTools MCP |
|---------|:---:|:---:|
| Accessibility tree snapshot | `snapshot` | `take_snapshot` |
| What changed since the last snapshot | `diff` | - |
| Page content as Markdown, text, or links | `read` | - |
| Search the page text or snapshot | `grep` | - |
| Screenshot | `screenshot` | `take_screenshot` |
| Execute JavaScript in the page | `evaluate` | `evaluate_script` |
| Run a multi-step script against the browser | `run` | - |

### Interaction & Input

| Feature | Astro MCP | Chrome DevTools MCP |
|---------|:---:|:---:|
| Click, type, fill, hover, drag, press key | `act` | `click`, `fill`, `hover`, `drag`, `press_key` |
| Check / uncheck, select option, focus, scroll | `act` | - |
| Fill entire form | `act` (several fields) | `fill_form` |
| Upload file | `upload` | `upload_file` |
| Handle dialog (alert/confirm) | `act` (`dialog`) | `handle_dialog` |

### File & Export

| Feature | Astro MCP | Chrome DevTools MCP |
|---------|:---:|:---:|
| Save page as PDF | `pdf` | - |
| Download file via click | `download` | - |

### Windows & Tab Groups

| Feature | Astro MCP | Chrome DevTools MCP |
|---------|:---:|:---:|
| List, create, close, activate windows | `windows` | - |
| List, create, update, ungroup, close tab groups | `tab_groups` | - |

## Setup Comparison

<Tabs>
  <Tab title="Astro MCP">
    Astro MCP is built into the browser. No separate process, no debug flags.

    ```bash
    # One command, done (use the port shown on your settings page)
    claude mcp add --transport http browseros http://127.0.0.1:9239/mcp --scope user
    ```

    The server URL is shown at `chrome://browseros/mcp` (Settings → **Astro as MCP**). Copy it and connect.
  </Tab>
  <Tab title="Chrome DevTools MCP">
    Chrome DevTools MCP requires launching Chrome with remote debugging enabled and running a separate Node.js server.

    ```bash
    # Step 1: Launch Chrome with debug port
    /Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222

    # Step 2: Install and run the MCP server
    npx @anthropic-ai/chrome-devtools-mcp@latest

    # Step 3: Connect your MCP client to the server
    ```

    Some sites may block sign-in when the browser is controlled via WebDriver (the default launch mechanism).
  </Tab>
</Tabs>

## Summary

| Dimension | Astro MCP | Chrome DevTools MCP |
|-----------|:---:|:---:|
| MCP tools | **23** | **29** |
| External app integrations | **45** | **0** |
| Window management | Yes | No |
| Tab groups | Yes | No |
| Bookmarks & history | No | No |
| File export (PDF, downloads) | Yes | No |
| Content extraction (Markdown, text, links) | Yes | No |
| Console / network inspection | No | Yes |
| Performance tracing & Lighthouse | No | Yes |
| Memory snapshots | No | Yes |
| Device emulation | No | Yes |
| Setup complexity | Copy URL | Debug port + Node server |
| Browser session | Real (cookies, extensions) | Debug-attached (WebDriver flags) |

Astro MCP is the better fit for automation and app integrations through a single connection. Chrome DevTools MCP is the better fit for debugging and performance work.
