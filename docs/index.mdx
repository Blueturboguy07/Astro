Astro is an AI browser built on Chromium. Its new tab is an answer engine that searches the web and cites its sources. Its side panel assistant answers questions about the page you are on, or does a task for you in the browser. Astro is a fork of [BrowserOS](https://github.com/browseros-ai/BrowserOS).

**Open source. Your keys and chats stay on your computer.**

## Two Ways to Use the Assistant

<Columns cols={2}>
  <Card title="Chat Mode" icon="message">
    Ask questions about the page you're viewing. Summarize articles, extract data, translate content—without leaving the page.
  </Card>
  <Card title="Agent Mode" icon="robot">
    Describe a task and watch AI execute it: clicking, typing, navigating. Automate form filling, data extraction, and multi-step workflows.
  </Card>
</Columns>

## Quick Start

<Steps>
  <Step title="Download Astro">
    Get Astro from [publikhq.com/astro](https://publikhq.com/astro). Install guides: [Mac](https://publikhq.com/astro/install/mac), [Windows](https://publikhq.com/astro/install/windows). For Linux, see [SETUP.md](https://github.com/Blueturboguy07/Astro/blob/main/SETUP.md).
  </Step>
  <Step title="Import from Chrome">
    Navigate to `chrome://settings/importData` and import your bookmarks, passwords, and settings in one click.
  </Step>
  <Step title="Choose your AI">
    At the first start, Astro asks you to choose:

    - **Connect your plan**: sign in with your publik account. publik Balanced becomes the default model. publik Smart is also available, and publik Fast in the new tab. You pay publik per use.
    - **Use my own key**: add your own API keys or a local model.

    <Card title="Set up your LLM provider" icon="key" href="/features/bring-your-own-llm">
      Configure Gemini, Claude, OpenAI, or run models locally with Ollama
    </Card>
  </Step>
  <Step title="Try it out">
    Type a question in the new tab, or open any webpage and press the **Assistant** button in the toolbar. Ask a question about the page, or describe a task to automate.
  </Step>
</Steps>

## Which AI Model Should I Use?

<Tabs>
  <Tab title="For Chat Mode">
    **Any model works**, including local LLMs.

    - **publik Balanced**: the default after **Connect your plan**
    - **Ollama** or **LM Studio**: free, runs locally, good for quick questions
    - **Gemini Flash**: fast and affordable
    - **Claude or GPT-5**: high-quality responses

    Chat Mode just needs to understand the page and answer questions—local models handle this well.
  </Tab>
  <Tab title="For Agent Mode">
    **Use a strong cloud model for the best results.**

    | Model | Speed | Quality |
    |-------|-------|---------|
    | publik Smart | Slower | Best of the publik models |
    | publik Balanced | Medium | Great |
    | Claude Opus 4.5 | Slower | Best |
    | Claude Sonnet 4.5 | Medium | Great |
    | Gemini Flash | Fast | Good |

    <Warning>
    Small local models run Agent Mode, but they often pick the wrong element or stop early on multi-step tasks. Use them for simple tasks.
    </Warning>
  </Tab>
</Tabs>
