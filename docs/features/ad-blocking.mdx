Astro has no ad blocker of its own. You can install the full [uBlock Origin](https://ublockorigin.com/) extension — not the reduced "Lite" version.

## Why This Works in Astro

Chrome [removed support](https://developer.chrome.com/docs/extensions/develop/migrate/mv2-deprecation-timeline) for Manifest V2 extensions, so Chrome users can only install "uBlock Origin Lite", which cannot use the advanced filtering rules.

Astro runs on BrowserOS's Chromium build, which keeps Manifest V2 support. So you can install and run the original uBlock Origin.

<Card title="Install uBlock Origin" icon="shield-check" href="https://chromewebstore.google.com/detail/ublock-origin/cjpalhdlnbpafiamejdnhcphjbkeiagm">
  Install the full uBlock Origin extension from the Chrome Web Store.
</Card>

## What This Means

Fewer ads means faster page loads, less bandwidth usage, and less tracking.
