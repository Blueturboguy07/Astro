---

Astro has no ad blocker of its own. Like Chrome, it loads ads and trackers until you install an ad-blocking extension.

## Install uBlock Origin Lite

The Chrome Web Store offers **uBlock Origin Lite**, the Manifest V3 version of [uBlock Origin](https://ublockorigin.com/). It installs in Astro like any other Chrome extension.

<Card title="Install uBlock Origin Lite" icon="shield-check" href="https://chromewebstore.google.com/detail/ublock-origin-lite/ddkjiahejlhfcafbddmgiahcphecmpfh">
  Install uBlock Origin Lite from the Chrome Web Store.
</Card>

<Note>
The full uBlock Origin (Manifest V2) is no longer available in the Chrome Web Store, so you cannot install it from there. Chrome [ended support](https://developer.chrome.com/docs/extensions/develop/migrate/mv2-deprecation-timeline) for Manifest V2 extensions. uBlock Origin Lite has fewer advanced filtering options than the full version.
</Note>

## What This Means

Fewer ads means faster page loads, less bandwidth usage, and less tracking.
