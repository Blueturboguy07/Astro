---
title: "Your Data Stays on This Device"
description: "Astro has no cloud sync: chats, settings and scheduled tasks stay on your computer"
---

Astro has no cloud sync. Astro opens with **Sign in with publik**, but that sign-in only connects your publik account (for the publik models and the usage counts). It does not copy your chats or settings to a server. Your data stays on the computer where you use Astro.

## What Astro Keeps on This Device

- **Conversations**: side panel chats and new-tab answers
- **AI connections**: your providers, model settings and API keys
- **Scheduled tasks**: the task setup and the run results
- **Connected apps** and the workspace folder selection
- **Theme** and other display settings

<Warning>
API keys are stored on this computer without encryption (in the browser profile and in the Astro server's settings file). Anyone with access to your user account can read them.
</Warning>

## Moving to a New Computer

Astro does not copy your setup to another computer. On the new computer:

1. Install Astro ([Mac](https://publikhq.com/astro/install/mac), [Windows](https://publikhq.com/astro/install/windows)).
2. Choose **Connect your plan** again, or add your API keys again.
3. Create your scheduled tasks again.

Chrome bookmarks, passwords and history can be imported with `chrome://settings/importData`.

## What Leaves Your Computer

- Your questions and page content go to the AI model you chose (your publik plan or your own provider).
- Web searches in the new tab go to the search engines.
- Connected apps (Connect Apps) run through a hosted Klavis service at llm.browseros.com, which BrowserOS operates. The app actions you ask for go through it to those apps.
