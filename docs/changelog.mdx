Astro's releases, with download links and full notes, are on [GitHub Releases](https://github.com/Blueturboguy07/Astro/releases). Astro is a fork of BrowserOS; changes that come from upstream are in [BrowserOS's releases](https://github.com/browseros-ai/BrowserOS/releases).

<Update label="0.2.4" description="November 11, 2026">
- The app opens with **Sign in with publik**. After the sign-in you choose once: **Connect your plan** (or **Get a plan**) or **Use my own key**. You can change the choice in Settings → Models.
- Usage counts: `app_opened` once per browser session and `active_session` every 30 minutes, with your install key. No content is sent. The switch is in Settings → Models.
- Self-test page: `app.html#/publik/self-test`.
- Agent extension 0.0.103. Files: `Astro.dmg` (macOS, Apple silicon), `Astro-Setup.exe` (Windows x64, unsigned).
</Update>

<Update label="0.2.2" description="November 6, 2026">
- Same as 0.2.1, plus anonymous usage counts (app opened, active session). No content is sent.
</Update>

<Update label="0.2.1" description="September 28, 2026">
- The About box, app menu, window title, onboarding page and `chrome://version` say Astro.
- First Windows installer (`Astro-Setup.exe`).
</Update>

<Update label="0.1.1" description="September 19, 2026">
- publik API becomes the default provider. Your own keys (Claude, Codex, Copilot, Ollama) still work in Settings → Models.
- The update feed points at publik, not at upstream BrowserOS. Automatic update checks are off: to update, download the new version.
</Update>

<Update label="0.1.0" description="July 31, 2026">
- First release: an answer engine that can use your browser (macOS, Apple silicon).
</Update>
