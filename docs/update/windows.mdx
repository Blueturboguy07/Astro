---
title: "Update on Windows"
description: "How to update Astro on Windows"
---

<Steps>
  <Step title="Download the latest version">
    Follow the [Windows install guide](https://publikhq.com/astro/install/windows) to download the latest Astro installer, or get it from [GitHub Releases](https://github.com/Blueturboguy07/Astro/releases).
  </Step>

  <Step title="Close Astro">
    Quit Astro completely before you run the installer.
  </Step>

  <Step title="Run the installer">
    Double-click the downloaded installer. Windows SmartScreen may warn you: click **More info**, then **Run anyway**.

    <Note>The install guide shows each step and the warnings you can expect.</Note>
  </Step>

  <Step title="Allow network access">
    When Astro opens, Windows may ask to allow its local server (`browseros_server`) to access the network. Click **Allow**. The assistant runs as a separate process next to the browser and needs this permission.

    <Warning>If you click Cancel, the assistant cannot reach its local server. Go to **Windows Security → Allow an app through firewall** and allow it.</Warning>
  </Step>
</Steps>

Your settings and data will be preserved after the update.
