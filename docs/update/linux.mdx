---
title: "Update on Linux"
description: "How to update Astro on Linux"
---

Astro has no standalone Linux build. On Linux, Astro's UI and agent run on top of an installed BrowserOS (see [SETUP.md](https://github.com/Blueturboguy07/Astro/blob/main/SETUP.md)).

<Steps>
  <Step title="Update BrowserOS">
    Download the latest BrowserOS AppImage or `.deb` (links in [SETUP.md](https://github.com/Blueturboguy07/Astro/blob/main/SETUP.md)) and replace your old copy.
  </Step>

  <Step title="Update Astro">
    In your Astro checkout, pull the latest code (`git pull`) and start Astro again as described in SETUP.md.
  </Step>
</Steps>
